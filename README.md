## 💼 Projects

### 1. Human Resource Management System (HRMS)

**Platform:** Salesforce CRM

**Technologies:** Salesforce CRM, Apex, SOQL, Flows, LWC, Reports and Dashboards

Developed a Salesforce-based HRMS project to organize consultant information and manage employee-related processes.

**Key Features:**

- Designed custom objects for Consultants, Clients, Projects, Bank Details, and Past Information.
- Configured custom fields, relationships, and validation rules.
- Automated onboarding activities using Record-Triggered Flows.
- Implemented Apex trigger logic to create Past Information records for interns.
- Added validation logic to prevent deletion of approved employee records.
- Configured Salesforce security using Profiles, Roles, Permission Sets, OWD, and Sharing Rules.
- Developed a Lightning Web Component to display consultant information using an Apex controller and SOQL.

### 2. Employee Leave Management System

**Platform:** Salesforce CRM

**Technologies:** Salesforce CRM, Apex, SOQL, Flows, Approval Processes, Reports and Dashboards

Built a Salesforce application to manage employee leave requests and approval workflows.

**Key Features:**

- Designed custom objects for Employees, Projects, and Leave Information.
- Configured validation rules for leave dates and leave duration.
- Automated leave-day calculations using Flow Builder.
- Implemented an Approval Process for manager approval or rejection.
- Developed Apex trigger logic to prevent overlapping leave requests.
- Configured email notifications for leave status updates.
- Created reports and dashboards to track leave information.

## 🚀 Setup and Installation

### Prerequisites

- A modern web browser
- Visual Studio Code
- Git (optional, for cloning the repository)

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/soniyarathod/soniya-portfolio.git
   ```

2. Open the project folder in Visual Studio Code.
3. Run `index.html` using the Live Server extension.
4. Open the local URL provided by Live Server.

### Deploy Using GitHub Pages

1. Open the repository on GitHub.
2. Navigate to **Settings → Pages**.
3. Select **Deploy from a branch**.
4. Choose branch `main` and folder `/(root)`.
5. Click **Save** and wait for deployment.
